# 🍽️ Restaurant Landing Page

A modern and responsive **Restaurant Landing Page** designed to showcase a restaurant's menu, services, gallery, and contact information. The project focuses on attractive UI, proper spacing, smooth navigation, and a mobile-friendly experience.

## ✨ Features

* 🏠 Hero Section with CTA
* 📖 About Restaurant section
* 🍴 Menu showcase
* 🖼️ Food Gallery
* 📍 Contact Section
* 🧭 Smooth scrolling navigation
* 📱 Fully responsive design
* ✨ Hover effects and smooth transitions
* 🎨 Attractive and clean UI
* 📐 Responsive layout for different screen sizes

## 🛠️ Technologies Used

* **HTML5** – Website structure
* **CSS3** – Styling, layout, responsiveness, and animations
* **JavaScript** – Navigation and interactive elements
